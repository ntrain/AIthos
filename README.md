# AIthos
AIthos is a values-driven chatbot that listens with empathy, responds with respect, and fosters meaningful conversation. Designed to be ethical and emotionally aware, it bridges the gap between artificial intelligence and human connection.

## About The Project
AIthos explores how conversational AI can feel more human‑centered. Instead of repeating canned lines, it uses intent detection, varied responses, and subtle UX touches (like typing animations and fade‑ins) to create authentic flow.

**Features**
- Elegant UI with background image and dual borders.
- Typing indicator (`...`) simulating AI “thinking.”
- Expanded response library (empathy, curiosity, encouragement, neutral).
- Intent detection to match tone to user input.
- Feedback asked **once only** at the end.

## Built With
- **HTML5** — chatbot structure  
- **CSS3** — styling, animations, polished UI  
- **JavaScript (ES6)** — logic, intent detection, typing indicator, feedback flow  

## Getting Started
To get a local copy up and running, follow these steps:

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, Safari).
- Git installed on your computer (optional if you download the ZIP).

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/ntrain/AIthos.git
   cd AIthos

### Running Locally
Open index.html in your browser to start the chatbot.
No server setup is required — it runs as a static site.

### Deployment
- Enable GitHub Pages in your repo settings.
- Set the source branch to main (root).
- Your site will be live at:
   https://ntrain.github.io/AIthos/

### Usage
- Type a message and press Enter or click Send.
- AIthos shows a typing indicator, then responds with varied, intent-based replies.
- After several exchanged, it gently asks:
  "Before we wrap up, how was your experience with AIthos today?"
This create a respectful, authentic chatbot experience.
